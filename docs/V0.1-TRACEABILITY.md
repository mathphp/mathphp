## Local verification record

The frozen suite contains 513 tests and 5,375 assertions.

`composer quality` passed under PHP 8.4.16 and performed:

- `composer validate --strict`;
- optimized autoload generation with `--strict-psr` and
  `--strict-ambiguous`;
- syntax checks for all 45 project PHP files;
- the complete PHPUnit suite;
- PHPStan at `level: max` with `phpVersion: 80200`; and
- PSR-12 checks.

The minimum-runtime PHPStan and PSR-12 commands also passed when invoked
explicitly with PHP 8.2.30. PHPStan required permission to bind its loopback
worker socket; the completed analysis reported no errors and uses no baseline
or ignored-error rules.

The locked, network-backed command:

```console
composer audit --locked --no-interaction
```

reported no known security vulnerability advisories.

## Architecture and safety review

- Runtime requirements contain only PHP `^8.2`; all third-party packages are
  development tools.
- Source contains no PHP `eval`, arbitrary string-to-callable lookup,
  `call_user_func`, process execution, filesystem/network access, mutable static
  property, or global evaluation state.
- The only callback invocation is the private `Closure` stored in an explicitly
  constructed `FunctionDefinition`; expression text can only select an
  immutable registered definition.
- Built-in provenance is immutable registry-owned state. A custom definition
  has no constructor flag or mutable property with which to forge built-in
  error semantics.
- `Math::evaluate()` creates a fresh environment, lexer, parser, numeric
  operations object, and evaluator for every call.
- Source errors use byte spans and stable codes; invalid host construction uses
  `InvalidArgumentException`.
- Integer overflow, non-finite values, signed zero, division/modulo edge cases,
  factorial bounds, exponent bounds, and cross-call isolation have direct
  boundary tests.
- Malformed-number scanning includes a sign immediately following any exponent
  marker in the contiguous malformed run, including repeated-marker cases.
- The documented local Composer path-repository installation was installed in
  an isolated consumer and its autoloaded facade returned exact integer `512`
  for `2^3^2`.

## Release decision

The implementation, documentation, local compatibility work, and local
quality/security gates are complete. No repository was initialized and nothing
was published, tagged, pushed, or advertised.

An actual `0.1.0` release still requires:

1. remote PHP 8.3 CI evidence; and
2. separate explicit approval to initialize/use a repository and publish.
